# Parkinson's Disease Prediction using Machine Learning

## 📌 Project Overview
This project predicts Parkinson's Disease using Machine Learning techniques in Python.

The model is trained using biomedical voice measurement data to identify whether a person is affected by Parkinson's Disease.

---

## 🚀 Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

---

## 📊 Features
- Data preprocessing
- Feature selection
- Model training
- Prediction system
- Accuracy evaluation

---

## 🎯 Result
Achieved approximately 95% prediction accuracy.
